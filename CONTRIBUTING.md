# Contributing

Contributions should improve source accuracy, reproducibility and ethical research practices.

1. Open an issue describing the proposed change.
2. Cite primary or peer-reviewed sources for factual claims.
3. Do not submit fabricated data, results, references or screenshots.
4. Do not upload confidential employer/client information or identifiable survey responses.
5. Run `pytest -q` for Python changes.
6. Explain assumptions, units, forecast horizon, data provenance and known limitations.

This repository supports an academic research project; final interpretations remain subject to real evidence and guide approval.
